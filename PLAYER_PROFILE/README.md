# Профиль игрока (словари в Python)

Учебный проект Т118. Персонажи вымышлены.

## Запуск

```
python player_profile.py
```

## Возможности

Каждый игрок — словарь с ключами `name`, `health`, `score`.
Три игрока лежат в списке словарей `players`.

| Команда | Действие |
|---|---|
| 1 | показать профиль текущего игрока |
| 2 | добавить очки |
| 3 | нанести урон |
| 4 | выбрать игрока (номер 1–3) |
| 5 | показать всех игроков |
| 6 | показать лидеров по очкам (все, если очки равны) |
| 0 | выход |

## Правила

- Очки и урон — положительные целые числа.
- Здоровье не опускается ниже нуля.
- Отклонённое действие не меняет данные.
- Буквы вместо числа и неизвестная команда не останавливают программу.

## Где что находится

- **Состояние** — список `players` и переменная `current` в функции `main()`, создаются до цикла меню.
- **Проверки** — внутри игровых функций `add_score` и `take_damage` (положительность), `read_int` (число), `choose_player` (номер игрока).
- **Лидеры** — `find_leaders`: первый цикл ищет максимум очков, второй собирает всех с этим значением.
